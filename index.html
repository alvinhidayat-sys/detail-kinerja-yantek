Rumus mengikuti logika Sheet "Petugas" (Dashboard) pada file Excel referensi: WO dicocokkan lewat No Laporan (CICO WO → Detail WO), SLA WO dicocokkan lewat Fasilitas|Subfasilitas|Peralatan, dan Koefisien Unit dicocokkan lewat Nama UP3. P0 dicocokkan lewat No Penugasan Khusus (CICO P0 → Detail P0), SLA P0 dicocokkan lewat Jenis Penugasan, dan Koefisien Unit dicocokkan lewat Area Petugas. Tidak ada data dari file Excel yang digunakan — seluruh data diambil langsung dari spreadsheet di atas.
